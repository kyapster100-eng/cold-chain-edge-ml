# cold-chain-edge-ml
An ESP32 Edge-IoT framework for real-time cold-chain quality prediction using multimodal sensor fusion (T, H, L, V). Running an embedded C++ Decision Tree, it delivers 89.9% accuracy, 90.2% F1-score, and 92.0% spoilage recall at &lt;20 ms latency without cloud reliance, complete with firmware filtering for real-world sensor noise.
